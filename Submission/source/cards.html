The problem

Agents get hijacked by text on web pages.

A review, a hidden banner or a "policy notice" can tell a shopping agent whom to pay, what to buy and where to ship. Prompt injection succeeds against a large share of agents in current benchmarks.

When an agent buys wrong, nobody knows who pays.

The user's wording, the merchant's listing and the agent's choice all contributed. No rule assigns the fault, so the money stays where it fell.

Provenant solves both, on PayPal rails.01 / problem
